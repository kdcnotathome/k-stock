# K STOCK｜臺股觀察室

股票查詢、盤後籌碼、技術分析與個人研究紀錄，免登入、免付費 API 金鑰。網站不顯示任何版本編號。

## 已提供的功能

- 以股票代號或名稱搜尋上市、上櫃股票與 ETF；查看最近可取得的收盤價、開高低、成交量、成交金額。
- 每五分鐘自動檢查官方資料，也可手動檢查；顯示來源交易日期與網站檢查時間，**不宣稱盤中即時行情**。
- 個股「三大法人」：上櫃股票接入證券櫃檯買賣中心 `tpex_3insti_daily_trading` 開放資料，顯示外資及陸資（不含外資自營商）、投信、自營商及三大法人合計的**單日買賣超**，原始股數換算為張（1 張＝1,000 股）。上市三大法人 T86 逐檔日報的公開網站二次展示權限尚未核實，因此僅提供 TWSE 官網查詢入口，不在本站擷取轉播。
- 個股「融資融券」：上市 `MI_MARGN`、上櫃 `tpex_mainboard_margin_balance`，顯示最新餘額、前一交易日增減，單位張；如某官方列未附日期，頁面誠實顯示「日期未提供」。非信用交易標的可能沒有資料。
- 個股「技術分析」：官方歷史月報為基礎，顯示日 K 線、成交量、MA5/10/20/60、MA20 乖離率、最近 5 個交易日明細。**均線由本站依未還原收盤價計算，除權息可能使技術指標產生跳空。**
- 保留估值指標、自選股、成本與目標價、研究筆記、JSON 匯入／匯出，以及證交所即時行情官方連結。
- 自選股和研究紀錄只存於各自瀏覽器 `localStorage`，不會上傳給本站，也不會在使用者間同步。重新安裝瀏覽器或清除網站資料之前，請自行匯出備份。
- 無法取得官方資料時，顯示原因，不以假資料冒充真實行情。互動示範的股價為測試數字，法人及融資券資料不提供假資料。

## 官方資料與引用

- [臺灣證券交易所 OpenAPI](https://openapi.twse.com.tw/)
- [證券櫃檯買賣中心 OpenAPI](https://www.tpex.org.tw/openapi/)
- [櫃買中心上櫃三大法人買賣明細（開放資料）](https://data.gov.tw/dataset/11856)
- [櫃買中心上櫃融資融券餘額（開放資料）](https://data.gov.tw/dataset/11387)
- [政府資料開放授權條款第 1 版](https://data.gov.tw/license)

TWSE 個股歷史價格及 TPEx 個股歷史價格由其官方歷史查詢服務取得，用於本站自行計算技術指標。這些傳統歷史報表的資料利用規範，應與相應網站服務使用條款核對；如官方規定或系統回應變更，請保留來源連結並停用受影響項目。官方 OpenAPI 亦可能在 Render 資料中心遭遇連線限制。

**風險提醒：** 頁面不是投資建議、非交易所官方網站，歷史走勢不代表未來績效。

## 啟動及檢查

Node.js 20 或更新版本：

```bash
npm start
```

在 http://localhost:3000 查看網站。測試：

```bash
npm test
```

## GitHub + Render 更新方式

您目前的網站：`https://k-stock.onrender.com`；儲存庫：`kdcnotathome/k-stock`。

1. 在 GitHub 儲存庫**最外層**上傳 `server.js`、`analytics.js`、`README.md`，取代同名檔案；`analytics.js` 是新檔。
2. 進入 GitHub 儲存庫的 `public` 資料夾，上傳 `index.html`、`app.js`、`analytics-ui.js`、`analytics.css`，取代同名檔案；後面兩個是新檔。
3. 提交到 `main` 後，Render 預設自動部署；若沒有，可從 Render → `k-stock` → **Manual Deploy → Deploy latest commit**。
4. 顯示 **Live** 後開啟原本網址，按 **Ctrl+F5** 以清除舊前端快取。
5. 分別測試 `6488` 的「三大法人」、`2330` 的「融資融券」與「技術分析」。

檔案中的 `test/` 是範例資料的單元及 API 行為測試；測試通過不代表已從雲端主機成功取得所有官方資料，實際仍須以上線測試為準。
