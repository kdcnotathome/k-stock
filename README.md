# K STOCK｜臺股觀察室

以您提供的既有 K STOCK 程式為基礎，重新設計的臺股公開行情查詢與個人研究網站。

## 已完成的操作

- 在搜尋框輸入「台積電」或「2330」，查找官方最新交易日的上市、上櫃股票與 ETF。
- 查看收盤價、漲跌、漲跌幅、開高低、成交量、成交金額、成交筆數，以及資料所屬的交易日期。
- 查看上市股票近期官方歷史成交價格折線圖（來源暫時無法連線會顯示說明），以及官方估值指標（本益比、殖利率、股價淨值比）。
- 加入／移出自選股、填寫持有股數、每股成本、目標價與研究筆記，計算參考損益。
- 匯出及匯入 JSON 備份。
- 內建「互動示範」供無法連接官方 API 時試用；**示範價格是虛構測試資料，絕非市場行情**。
- 沒有會員、登入或密碼；公開網址可讓任何人使用，**每個人的自選股及筆記存在自己的瀏覽器 localStorage，彼此不會同步**。

## 行情時效與使用界線

免費串接來源為：[TWSE OpenAPI](https://openapi.twse.com.tw/) 與 [TPEx OpenAPI](https://www.tpex.org.tw/openapi/)。所顯示的是「最近可取得的交易日收盤行情」，**不是盤中逐筆即時成交資料**。上市走勢另外使用證交所的個股月份歷史行情服務；部分資料可能因官方接口限制、網路或格式異動而無法取得。

網站提供「前往證交所官方即時行情」連結供自行查看。依據證交所資訊服務 FAQ，將集中市場即時交易資訊再傳輸供他人使用可能需要事先取得同意、簽訂契約；若要公開播送即時行情，請先與交易所確認授權。

沒有投資建議或自動下單功能。網站不是交易所的官方網站。

## 本機操作

安裝 [Node.js](https://nodejs.org/) 20 以上版本，將 ZIP 解壓縮後，在該資料夾開啟終端機：

```bash
npm start
```

開啟 http://localhost:3000 。

若只想先試用操作，可直接開啟另外提供的 `K_STOCK_互動預覽.html`，不需要安裝 Node.js；預覽顯示示範數據，不會載入即時行情。

## 公開部署，讓朋友都能開啟

**Render Web Service** 方式（無須自己維護伺服器）：

1. 將本 ZIP 內的 `public/`、`server.js`、`package.json` 及 `README.md` 上傳到您自己的 GitHub 專案儲存庫。
2. 登入 [Render](https://render.com/) → New → Web Service → 連接 GitHub 儲存庫。
3. Runtime 選 Node；Build Command 填 `npm install`；Start Command 填 `npm start`。
4. 部署後即可取得 `https://...onrender.com` 公開網址，直接分享給朋友，無須登入 K STOCK。
5. Render 免費資源可能休眠，第一次開啟可能載入較久。某些雲端資料中心可能遭官方來源限制；正式對外公開前需驗證臺灣網路能夠成功取得上市及上櫃官方資料。

本套件尚未直接部署至任何網站，所以下載 ZIP **並不等於已經有公開網址**。

## 檔案說明

- `server.js`：Node.js HTTP 伺服器、股票 API 代理與快取。
- `public/index.html`：網站頁面。
- `public/styles.css`：網頁設計（桌機、手機）。
- `public/app.js`：搜尋、選股、筆記、自選股與互動操作。

## 技術細節

- 同網域 API 代理，避免瀏覽器直連交易所 CORS 限制。
- 基本 API 請求速率限制、上游資料快取與無效數值處理。
- 所有行情欄位維持來源日期與顯示時間語意，不冒充盤中報價。
- 自選股價屬「加入時的行情快照」，點選查看才會重新載入官方資料。
